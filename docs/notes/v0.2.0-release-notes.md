Second minor release: realtime liveness, fleet-table output options, and a hardened security posture. Core API is fully additive since v0.1.0 — no breaking changes (15 exported symbols intact; `FileStore` moved from `reporter.go` to its own `filestore.go`, same package).

## Highlights

**Realtime promise kept**

- go-filewatcher/v2 dir-watch over the cache DB + WAL sidecars and the evidence file's directory: cross-process SQLite writes and atomic evidence renames now refresh the dashboard in ~1-2s instead of waiting on the 5-minute safety net (which stays as backstop)
- New non-critical `evidence-watch` readiness check makes a dead watcher visible in `/readyz`

**Fleet table output options (producer flag parity)**

- `--format` renders the fleet table in 11 go-output formats (CSV/JSON round-trip specs included)
- `--sort-by` retiebreaks findings/failures/name inside the state rank; machine formats sort identically and the default keeps the canonical order byte-identical

**Security**

- `go1.27.4` toolchains close GO-2026-6859 (govulncheck: 0 reachable in both modules)
- `X-Content-Type-Options: nosniff` middleware on every response; `SECURITY.md` added

**Dashboard**

- Compiled Tailwind CSS pipeline replaces the Play CDN: `scripts/regen-ui.sh`, tracked class inventory, content-hash-versioned `/app.css` with ETag/304; CI `css-freshness` gate keeps artifacts byte-fresh
- Styled 404 for every unknown path (`errorpage.NotFound404` in the dashboard shell); dark mode with pre-paint theme script + toggle

**Robustness & contracts**

- Discovery watch-stream parsing hardened (`ParseSSEData`: WHATWG multi-line `data:` reassembly, over-cap lines fail loudly); utilization-report citations mechanically gate-verified (`check-citations.sh` with a working baseline ratchet)
- Probe-first unix-socket binding: a second hub never steals a live sibling's socket — it refuses with a clear error
- Sysexits exit-code contract for embedders: transient IO = 75, rejection = 1, internal = 69
- Humanized relative times across the CLI (table age column, header window-age, stall messages): "3h0m0s ago" → "3 hours ago" via go-humanize; threshold comparisons stay exact

**Dependency & platform**

- go-sse v0.7.0, go-datastar v0.7.0 (+ datastartest), go-output v0.38.7 sub-modules, go-error-family v0.12.0, go-filewatcher/v2 v2.5.0, templ-components v1.27.0 (`errorpage`), go-humanize v1.1.0
- CI matrix activated: 14 jobs green, including new citation-gate, css-freshness, cmdguard-usage, branded-ID (BD003), and templ-fmt gates; `-race` parity on both modules
