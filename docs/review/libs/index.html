02Cross-cutting findings

Should adopt

go-filewatcher: the realtime promise leaks through a 5-minute hole

hub/internal/cli/serve.go:58-60 · flags.go:22 · refresher.go:25

The OnWrite trigger fires only for *cache.Store; the DEFAULT --source file has no write trigger at all, and cross-process SQLite writes only surface via the 5-minute safety-net ticker. Directory-level watching (the lib only accepts directories — ErrPathNotDir forces the correct shape) catches WAL sidecar commits and the reporter's atomic renames in ~1-2s, with Healthy() slotting straight into the go-health probe and the safety net retained as backstop. Cost: fsnotify + 3 first-party deps, one STACK.md row, the vendorHash ritual.

Convergence

Two independent groups flagged the same hand-rolled SSE parser

hub/internal/discovery/client.go:184-201

Group A (via go-daemon) and group B (via go-sse/sseparse) each found the discovery client's bufio.Scanner + data:-prefix parser: it drops multi-line data: frames and never checks scanner.Err() (gopls-flagged) — read errors masquerade as clean EOF on the liveness input for never-covered. daemon.ParseSSEData (WHATWG-conformant) already sits in an imported module: zero new dependencies.

Routed TODO_LIST High Impact — swap to ParseSSEData (or promote sseparse).
Strictly weaker

go-daemon: the hub re-implements the library's central contract, worse

hub/internal/cli/bind.go:31-127 · /home/lars/projects/go-daemon/socket.go:394

Only 4 sd_notify calls are used; ~90 LOC re-implement Server.Start's bind/serve/drain/unlink ordering. The hand-roll is strictly weaker: bind.go:46 removes an existing unix socket unconditionally, while CleanStaleSocket probes the old socket's health endpoint first and refuses to steal a live daemon's socket. This is the fleet anti-pattern go-daemon exists to amortize.

Routed TODO_LIST High Impact — probe-first socket cleanup or full lifecycle adoption.
Fleet contract

Hub exits generic 1; classifications never reach exit codes

hub/cmd/compliance-hub/main.go:14

go-error-family is the fleet classification/exit-code standard (135 consumers, STACK.md ★) and core's integration is canonical — but the hub never consumes a classification: rg 'compliance.Err|errorfamily.' hub/internal → zero hits. A transient cache-open failure should exit the fleet-standard 75, not 1. One line: errorfamily.ExitCode(err).
